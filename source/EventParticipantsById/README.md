# People with Event ID

This Gramps Person filter rule finds all people who reference one event,
regardless of their event role. Enter the event's exact Gramps ID (for
example, `E0012`).

The rule is registered for Gramps 5.2, 6.0, and 6.1. See the repository's
README for Addon Manager project URLs and installation instructions.
