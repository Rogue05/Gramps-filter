# Events by Role

**Events by Role** is an alternate Gramps Events view. It displays events as
rows and gives every standard event role and every custom role in the active
tree its own participant column. People and families are both included.

Names in a cell are separated by semicolons. An empty cell means that no
participant has that role for the event. The standard Events view remains
available as a separate view mode.

The view is registered for Gramps 5.2, 6.0, and 6.1. See the repository README
for Addon Manager installation instructions. Licensed under GPL-2.0-or-later;
see `LICENSE`.
